## Instalación (cliente)

1. Descarga `PantheonCata-V6-FIXED.zip`.
2. Cópialo a `%appdata%\.minecraft\resourcepacks`.
3. Actívalo en *Options → Resource Packs*.
4. Usa **Fabric con [EMF](https://github.com/Traben-0/Entity_Model_Features) + [ETF](https://github.com/TeamMidnightDust/EntityTextureFeatures)** para ver skins aleatorios, modelos custom (`.jem`) y emisivas de OptiFine.
