# TexturesCata

Resource packs de TheCataclysmSMP para **Minecraft 1.21.5** (Fabric).

## Packs

| Pack | Versión | Contenido |
|---|---|---|
| `CataclysmTexture.zip` | V1 | Retexturas base de mobs + audio minimo (1 tema). ~17 MB |
| `CataclysmTexture2.zip` | V2 | Retexturas base + skins aleatorios + 23 temas de jefes. ~184 MB |
| `PantheonCata.zip` | V5.5 (recomendado) | Igual que V2 + badges de equipos actualizados. ~184 MB |

## Instalación (cliente)

1. Descarga el `.zip` (uso recomendado: `PantheonCata.zip`).
2. Cópialo a `%appdata%\.minecraft\resourcepacks`.
3. Actívalo en *Options → Resource Packs* (o el servidor te lo fuerza).
4. Versión **Fabric con [EMF](https://github.com/Traben-0/Entity_Model_Features) + [ETF](https://github.com/TeamMidnightDust/EntityTextureFeatures)** para ver skins aleatorios, modelos custom (`.jem`) y emisivas de OptiFine.
